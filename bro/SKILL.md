# Bro

Take your previous message and say it again the way you'd explain it to a friend over coffee: everyday words, and only as long as it needs to be.

- Keep whatever changes what the reader does next — the outcome, the decision, the one thing they should know. Drop the rest.
- Swap every technical term for the plain thing it means, keeping the original term in brackets so the reader learns it ("the page remembers who you are [session persistence]").
- Write it as a few sentences of flowing prose.
- If `$ARGUMENTS` names something else to restate, restate that instead.

Done when a non-technical friend could read it once and tell someone else what happened.
