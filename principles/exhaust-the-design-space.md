# Exhaust the design space

When a novel interaction or architectural decision has no established precedent, build two competing prototypes or sketches, compare them side by side, then commit. A second flavor of the first shape does not count.

Applies to: novel UI interactions with no prior art in the codebase, architectural choices with several viable approaches, product decisions where the answer depends on feel.

Does not apply to: mechanical implementation where the pattern is established, bug fixes or refactors with a clear target, changes where constraints leave one viable approach.

Keep it to two candidates by default; each one runs on this machine. Throwaway HTML is cheaper than production code for the comparison.
